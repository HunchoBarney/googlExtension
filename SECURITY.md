# Security Policy

## Supported version

Only the latest tagged release is supported.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's security-advisory feature. Do not open a public issue containing exploit details, credentials, private browsing information, wallet data, or other sensitive material.

Include the affected version, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgment within seven days.

PMEx is read-only. A report involving wallet access, signing, order submission, or credential storage indicates behavior outside the intended product boundary and should be treated as high priority.
